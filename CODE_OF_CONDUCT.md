# Code of conduct

We want collaboration on Defuse Protocol to be constructive, welcoming, and safe.

Contributors must communicate respectfully, critique ideas rather than people, avoid harassment and discriminatory language, respect privacy, and comply with project licensing and originality rules. Maintainers may edit or remove contributions and participation that violate these expectations.

Report conduct concerns privately to the repository owner through a private GitHub channel when one is configured. Do not include personal or sensitive information in public issues.
