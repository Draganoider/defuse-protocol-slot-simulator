# Contributing to Defuse Protocol

Thank you for helping improve this educational simulator.

## Before contributing

1. Read `AGENTS.md` and the documentation index in `docs/README.md`.
2. Keep the project virtual-credit-only and suitable for a public repository.
3. Open an issue before changing foundational mathematics, architecture, licensing, or visual identity.
4. Never contribute copied commercial-game assets or material without a documented compatible license.

## Development expectations

- Keep the mathematical engine independent from rendering and UI code.
- Add or update tests for behavioral changes.
- Update the relevant documentation in the same pull request.
- Record foundational decisions in `docs/adr/`.
- Keep pull requests focused and explain how the change was verified.
- Do not commit secrets, local configuration, dependency folders, build output, or unreviewed generated assets.

## Artwork and audio

Every committed media asset must have a provenance record describing its creator or generator, creation date, source prompt or source material where applicable, edits, license, and reviewer. References may guide mood and genre, but contributed assets must not reproduce protected characters, maps, skins, logos, interface elements, or audio.

## Reporting problems

Use GitHub issues for ordinary bugs and feature proposals. Follow `SECURITY.md` for vulnerabilities or accidental secret exposure.
