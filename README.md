# Defuse Protocol

Defuse Protocol is a playable, original educational slot-machine simulator with a tactical-industrial presentation. It uses transparent slot rules to demonstrate seeded randomness, payline evaluation, feature frequency, RTP sampling, and the difference between bonus routes with similar expected value but different volatility.

> [!IMPORTANT]
> Defuse Protocol uses virtual credits only. It has no deposits, purchases, withdrawals, prizes, cryptocurrency, cash-out flow, or real-money gambling integration.

## Project status

The working prototype includes:

- a five-reel, three-row game with 20 fixed paylines;
- explicit circular reel strips, a declared paytable, WILD substitution, and CORE scatter entry;
- deterministic `mulberry32-v1` randomness with canonical seeds and replay metadata;
- Relay Alpha and Relay Bravo feature routes, retriggers, and a 30-spin award cap;
- a React application shell and PixiJS reel presentation;
- an original Pelagos Relay environment plus production artwork for CORE, WILD, and RECOVERY, with procedural fallbacks for the remaining symbol family;
- high-volume, route-specific simulation in a Web Worker;
- theoretical base-game and bonus-frequency analysis plus clearly labeled observed statistics;
- a development-only QA menu for forcing 3, 4, or 5 CORE bonus offers; and
- automated engine, replay, feature, validation, simulator, and worker-parity tests.

Every spin result is generated by the engine before presentation begins. Animation displays the immutable result; it does not select or alter it.

## Math snapshot

The current configuration has an exact theoretical bonus-entry probability of `0.00856`, or approximately **one bonus in 116.82 paid spins**. The exact theoretical base-game RTP is **29.3169%**.

A deterministic `tune-v1` sample of 200,000 paid spins per route produced:

| Route | Statistic | Observed value |
| --- | --- | ---: |
| Relay Alpha | RTP | 96.7042% |
| Relay Alpha | Conditional feature payout | 1,629.97 virtual credits |
| Relay Alpha | Paid-spin return standard deviation | 9.9716 return-multiple SD |
| Relay Bravo | RTP | 94.6083% |
| Relay Bravo | Conditional feature payout | 1,553.43 virtual credits |
| Relay Bravo | Paid-spin return standard deviation | 10.7774 return-multiple SD |

These route figures are observed sample statistics, not theoretical promises or controls applied to individual results. Full provenance and caveats are in the [tuning report](docs/tuning-report.md); the rules are described in the [mathematical model](docs/math-model.md).

## Local development

Requirements: Node.js 22.12 or newer and npm 11.

```bash
npm ci
npm run dev
```

The local development build exposes a clearly labeled QA cheat menu. It fabricates a marked pending bonus choice without consuming the random stream. Cheat-generated feature results remain marked as developer-generated and are structurally separate from ordinary spins and simulation.

Before proposing a change, run:

```bash
npm run typecheck
npm test
npm run build
```

## Technology

- TypeScript for the independent mathematical engine and application code
- React and Vite for the application shell and build pipeline
- PixiJS for the rendered reel scene
- Web Workers for high-volume simulations
- Vitest for deterministic unit and integration tests
- Playwright for browser-level verification where the environment supports it

See the [documentation index](docs/README.md), [architecture](docs/architecture.md), and [prototype QA report](docs/qa-report.md) for implementation details and current verification status.

## Visual and audio status

The first production visual slice is implemented. The game now uses original generated runtime artwork for the Signal Core (`CORE`), Containment Specialist (`WILD`), Recovery Case (`RECOVERY`), and the Pelagos Relay environment. Remaining regular symbols retain original procedural rendering until their reviewed artwork is produced. Richer reel motion, route-specific VFX, and production audio remain future work.

Every runtime image has a public brief, sanitized prompt record, technical-preparation notes, and an approved provenance entry under [`docs/assets/`](docs/assets/). Future assets must follow the same [art direction](docs/art-direction.md), provenance rules, and public-repository license policy.
