# Security policy

## Supported versions

Defuse Protocol is currently in pre-production. Security fixes apply to the latest revision of the default branch.

## Reporting a vulnerability

Do not publish exploitable details or exposed credentials in a public issue. Use GitHub's private vulnerability-reporting feature when it becomes available for the repository. Until a private channel is configured, provide a minimal public report that contains no secrets, personal data, or reproduction details that would increase risk.

This project must never request gambling deposits, payment credentials, wallet keys, or identity documents. Treat any code that introduces those flows as out of scope and security-sensitive.
